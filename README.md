# ระบบลงเวลา–OT (PSA-HKT / Globex) — Apps Script Web App

Prototype ลงเวลาเข้า-ออกงานรายวัน + คำนวณ OT แยกประเภท + อนุมัติโดย Supervisor
(**ลายเซ็นอิเล็กทรอนิกส์ = การล็อกอินบัญชีองค์กร + เวลาเซิร์ฟเวอร์**) + Export PDF

## ไฟล์ในชุดนี้
| ไฟล์ | ใส่ใน Apps Script เป็น |
|---|---|
| `Code.gs` | ไฟล์สคริปต์ (.gs) |
| `Index.html` | ไฟล์ HTML ชื่อ **Index** |
| `Supervisor.html` | ไฟล์ HTML ชื่อ **Supervisor** |
| `Styles.html` | ไฟล์ HTML ชื่อ **Styles** |
| `appsscript.json` | manifest (เปิดแสดงใน Project Settings → Show appsscript.json) |

## ขั้นตอนติดตั้ง
1. ไปที่ https://script.google.com → **New project**
2. สร้างไฟล์ให้ครบตามตารางด้านบน แล้ววางเนื้อหาแต่ละไฟล์ (ชื่อไฟล์ HTML ต้องตรงเป๊ะ ไม่ต้องใส่ .html)
3. เปิด `appsscript.json`: Project Settings (เฟือง) → ติ๊ก **Show "appsscript.json"** แล้ววางทับ
4. แก้ค่าใน `Code.gs` ที่ `CFG`:
   - `SUPERVISORS` = ใส่อีเมลผู้มีสิทธิ์อนุมัติ (ผู้ตรวจรับ/หัวหน้ากะ)
   - `PDF_FOLDER_ID` = (ถ้าต้องการ) โฟลเดอร์ Drive เก็บ PDF
   - `SHEET_ID` = เว้นว่างได้ ระบบจะสร้างไฟล์ฐานข้อมูลให้เองครั้งแรก
5. **Deploy → New deployment → Web app**
   - Execute as: **User accessing the web app**  ← สำคัญ (เพื่อจับอีเมลผู้ล็อกอินเป็นลายเซ็น)
   - Who has access: **ผู้ใช้ในองค์กร (โดเมนของคุณ)**
6. เปิดครั้งแรกจะให้ Authorize สิทธิ์ → อนุญาต
7. ระบบสร้างชีต `TimeLog`, `Employees`, `Holidays` อัตโนมัติ
   - ใส่รายชื่อพนักงานจริงในชีต `Employees` (empId, empName, team)
   - ใส่วันหยุดในชีต `Holidays` (คอลัมน์ A = วันที่ yyyy-MM-dd) เพื่อให้แยก OT×1 / OT×3 ถูกต้อง

## การใช้งาน
- **พนักงาน** (`?page=checkin`): เลือกชื่อ → ลงเวลาเข้า → (ทำ OT) → ลงเวลาออก **หรือกดแจ้งลา AL/SL/BL**
- **Supervisor** (`?page=supervisor`): เลือกวัน → กด "✔ อนุมัติ" ทีละรายการ (รวมรายการลา) → "⬇ Export PDF"

## การลา (AL / SL / BL)
- พนักงานกด **แจ้งลาวันนี้** ในหน้า checkin (AL=พักร้อน, SL=ป่วย, BL=กิจ) — วันที่แจ้งลาแล้วจะลงเวลาเข้าไม่ได้
- รายการลาไปรออนุมัติในหน้า Supervisor เหมือนรายการลงเวลา และแสดงในรายงาน PDF (คอลัมน์ประเภทวัน)

## รายชื่อ Mock 80 คน
ครั้งแรกระบบ seed พนักงานตัวอย่าง **80 คน** (PSA001–PSA080, ชื่อไทยสุ่ม, ทีมสายการบินตาม TOR
Qanot Sharq / Red Wings / SCAT / LOT Polish / Azur Air / GullivAir / HiSky / Neos / S7)
ลงในชีต `Employees` — **แทนที่ด้วยรายชื่อจริงได้เลย** (แก้ในชีตโดยตรง เพิ่ม/เปลี่ยนชื่อ/ลบได้)

## ตรรกะแยกประเภท OT (แก้ได้ที่ฟังก์ชัน `computeOT` ใน Code.gs)
- **วันทำงาน** → ชั่วโมง OT ทั้งหมด = **OT×1.5** (112.50)
- **วันหยุด** → ชั่วโมงทำงานปกติ (≤ 8 ชม.) = **OT×1** (75) ; ช่วง OT = **OT×3** (225)

## หมายเหตุด้านหลักฐาน/กฎหมาย (เบื้องต้น ไม่ใช่คำปรึกษาทางกฎหมาย)
- ทุกรายการเก็บ audit trail: เวลาเซิร์ฟเวอร์ + อีเมลผู้ทำรายการ + เวลาที่อนุมัติ
- ลายเซ็นอิเล็กทรอนิกส์แบบล็อกอินนี้อ้างอิงได้ตาม พ.ร.บ. ว่าด้วยธุรกรรมทางอิเล็กทรอนิกส์ พ.ศ. 2544
  (ระบุตัวผู้ลงลายมือชื่อได้ + แสดงเจตนา + วิธีเชื่อถือได้ตามควรแก่กรณี) — เพียงพอสำหรับเอกสารตรวจรับภายใน
